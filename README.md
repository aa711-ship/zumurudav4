# مكياجات واكسسوارات زمردة — official frontend build

Static Arabic-first RTL storefront prototype with Turkish switch placeholder, product filtering, animated product reveals, gift finder, WhatsApp ordering, unique product IDs/URLs, and a redesigned contact section.

## Run locally

```bash
python -m http.server 8080
```

Then open `http://127.0.0.1:8080`.

## Demo data

Products are fictional placeholders. Replace product data/images later from the admin/backend.

## Security

See `SECURITY.md`. Frontend-only security cannot provide a real firewall or secure authentication. Use a CDN/host firewall/WAF plus a backend before production.
